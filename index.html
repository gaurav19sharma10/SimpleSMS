How Simple SMS Works

1

No Third-Party SMS Gateways

Simple SMS utilizes the real SIM cards inserted in your Android phone. No API fees or expensive monthly SMS gateway contracts.

2

Real-time Google Cloud Sync

When you send a message from this computer, it dispatches to your device's cellular radio via secure Firestore baseband queues.

3

Hardware Delivery Receipts

Cellular towers communicate directly with your phone's modem, reporting real delivery receipts back to this dashboard.

Firestore Security Rules

Make sure your Firebase project (simple-sms-c22dc) has rules set to allow read/write:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
